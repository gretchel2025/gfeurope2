Problem

Testers need a real-looking URL without public access.

The Netlify branch URL is useful for deploys, but testers should use dev.grandfeast.eu. That live dev site must be closed to random visitors.

Request Flow

Live dev checks happen before a page is served.

1. ClassifyHost or Netlify branch says live-dev
2. Bypass?Auth endpoints and assets can load
3. SessionNo session redirects to sign-in
4. RolesMissing tester or event role redirects to unauthorized
Admin Guard

Admin now means Supabase event role metadata, not just a session.

The /admin directory requires any admin-level access. Event routes under /admin/events/<event_id> require app_metadata.event_roles[event_id] with admin, or superuser. Global routes under /admin/global require superuser. On live dev, non-superusers must also have tester.

SessionProves identity.
App metadataStores permissions.
Event rolesDecide event admin access.
Sign-In

Redirects now preserve intent.

Signed-out protected requests go to /signin?redirectTo=.... Google sign-in uses that destination when present, and direct sign-in defaults to the configured public event landing page.

External Config

Netlify dev env now points at the tester URL.

APP_BASE_URL Netlify branch deploy: https://dev.grandfeast.eu
PUBLIC_SUPABASE_URL Netlify branch deploy: Supabase project URL
Supabase Auth Returns to /auth/callback on the app origin.
Cloudflare

The DNS/proxy path is now active for live dev.

Cloudflare now hosts authoritative DNS for grandfeast.eu. Production web and email records are DNS-only; dev.grandfeast.eu is proxied through the grandfeast-dev-proxy Worker to the Netlify dev branch origin. The Worker keeps traffic uncached and rewrites Netlify redirects back to the public host.

Verification

What proves this worked?

  • Unit tests cover production, local, live-dev, role combinations, and bypass paths.
  • npm run check, npm run test, npm run lint, and npm run build should pass.
  • dev.grandfeast.eu resolves through Cloudflare and serves the Netlify dev branch.
  • Live-dev tester, admin-only, and tester-plus-admin accounts show the expected access behavior.
  • Google OAuth returns through Supabase and then back to https://dev.grandfeast.eu/auth/callback.
